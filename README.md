# orima-campaign-manager
## オリウマ・キャンペーン管理ツール
オリウマレースキャンペーンの運営を支援する管理ツールです。
キャンペーンの開始日に合わせたスケジュール表示をはじめ、出走者管理、出走予定管理、絆スキル管理などの機能を備えています。
また、設定した連続出走数に達するとメッセージを表示し、出走状況の把握を促します。各種登録・変更内容はログとして保存されるため、キャンペーンの進行状況を確認できます。
